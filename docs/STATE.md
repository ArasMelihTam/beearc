Checklist rows now show a plain-language description under each factor.
- Factor picker (user decision, rule 7): inspection entry is two steps — checklist of factor groups (Brood, Stores, Condition, Varroa, Pests, Temperament; 56dp checkbox rows with desc) → form renders only ticked sections. First-time default: brood+stores+temperament ON, varroa OFF (most beekeepers skip counting). Back from form returns to checklist.
